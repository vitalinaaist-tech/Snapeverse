# Snapeverse Archive v2

Локальний архів сцен із Северусом Снейпом (`Severus Snape`) і Люціусом Малфоєм (`Lucius Malfoy II`). Сайт статичний: без бекенду, без бази даних, без хостингу. Оригінальні експорти та старі файли не змінювалися — усе створено в цій папці.

Швидкий старт:

- просто читати або переслати одним файлом — `Snapeverse_Offline_Media.html` (з медіа) або `Snapeverse_Offline.html` (легкий, без медіа);
- відкрити як сайт локально — `python -m http.server 8000`;
- опублікувати за посиланням — вміст `Snapeverse_Site.zip` на GitHub Pages, Netlify Drop або Cloudflare Pages.

## Як визначаються сцени

1. Скрипт читає `result.json` з Telegram-експортів і знаходить повідомлення, автор яких — рівно `Severus Snape` або `Lucius Malfoy II`.
2. Сцена починається з першого такого повідомлення й закінчується останнім у межах одного безперервного проміжку.
3. Усе, що писали інші учасники між цими двома повідомленнями, зберігається повністю.
4. Якщо після останньої репліки персонажа протягом 60 хвилин є відповіді на неї, вони теж додаються.
5. Новий проміжок починається, якщо персонаж мовчить понад 60 хвилин.
6. Цитати, на які відповідають учасники, додаються як «Контекст відповіді», щоб перехід за цитатою завжди працював.

Приватна сцена — це тривалий діалог одного персонажа з одним співрозмовником, навіть якщо інші учасники пишуть поруч. Скрипт шукає сильні фрази-початки (`ваш час начинается`, `ваш час начался`, `ваш личный час`, `приват`, `наедине`, `побеседовать с вами`, `время и внимание принадлежит вам` тощо), дивиться, кому відповідає персонаж або кого називає на ім’я, і підписує партнера. Дуже короткі сцени (менше 20 хвилин або менше 8 реплік персонажа) не вважаються приватними. Якщо сцена одночасно підходить під Хелловін і Приват, вона залишається лише Хелловіном.

## Локальний перегляд

Потрібен Python 3.9+.

```bash
python -m http.server 8000
```

Відкрийте <http://localhost:8000>. На телефоні в тій самій Wi-Fi мережі — `http://IP-комп'ютера:8000`.

`fetch()` не працює при відкритті `index.html` напряму через `file://`. Для такого випадку є офлайн-файли: просто відкрийте їх подвійним кліком або надішліть у Telegram.

## Один файл для пересилання

```bash
python build_singlefile.py
```

Отримаєте два варіанти:

- `Snapeverse_Offline_Media.html` (~70 МБ) — з усіма наявними фото, GIF і відео всередині;
- `Snapeverse_Offline.html` (~18 МБ) — легкий, лише текст і позначки типів медіа.

Обидва відкриваються без інтернету й сервера. На iPhone файл відкривається через «Поділитися → Відкрити в Safari», на Android — через файловий менеджер або «Відкрити в браузері».

## Публікація за посиланням

### GitHub Pages

1. Створіть репозиторій.
2. Завантажте `index.html`, `style.css`, `app.js`, `chats_data.json`, `manifest.webmanifest`, `sw.js`, `icons/`, `media/`, `.nojekyll`.
3. **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
4. Сайт буде за адресою `https://USERNAME.github.io/REPO/`.

Не завантажуйте в репозиторій папки `ChatExport_*`, `photos/`, `video_files/`, `result.json` — вони великі та містять особисті дані.

### Netlify Drop / Cloudflare Pages

Можна перетягнути папку з файлами сайту в Netlify Drop або підключити репозиторій до Cloudflare Pages. Обидва варіанти мають безкоштовний тариф. Посилання буде публічним для всіх, хто його має.

## Обмеження

- Аватарки за замовчуванням — кольорові кружки з ініціалами. Щоб поставити справжні фото, покладіть `avatars/severus.png` і `avatars/lucius.png` (PNG/JPG/WEBP) і повторно виконайте `python build_archive.py` та `python build_singlefile.py`.
- Великі JSON-експорти збережені без фото/відео: у них лише позначки «Фото», «Відео» тощо. Але в папці знайшлися HTML-експорти та медіатеки на ~103 000 файлів. Після повного скану вдалося точно зіставити **382 медіаповідомлення (379 унікальних файлів): 312 фото, 47 GIF, 20 відео, 3 стікери**. Решта — дублікати, стікери без підпису або файли, яких немає у вибраних сценах.
- Щоб додати **всі** гіфки, фото й відео, зробіть новий експорт Telegram Desktop із увімкненим завантаженням медіа (Photos, Videos, Stickers, GIFs), покладіть `result.json` і папки поруч із `build_archive.py` та виконайте:
  ```bash
  python build_archive.py
  python build_singlefile.py
  ```
  Скрипт підхопить нові файли й покаже їх у повідомленнях.
- «Привати» — евристика: строгий діалог 1-на-1 або сцена, де персонаж сам каже `приват` / `наедине`. Інші учасники можуть бути присутні як глядачі.
- Пошук працює по підрядках без морфології й синонімів: «северус» не знайде «снейп».
- За замовчуванням пошук шукає **точну фразу** (пробілки й переноси рядків неважливі). Для пошуку окремих слів перемкніть режим на **«Слова»**.

## Оновлення архіву

Покладіть новий експорт Telegram поруч зі скриптом або вкажіть шлях:

```bash
python build_archive.py "E:/path/to/result.json"
python build_archive.py "E:/path/to/export_folder" --gap 60
python build_singlefile.py
```

Без аргументів скрипт сканує батьківську папку, знаходить усі `result.json` і для кожного чату обирає найповніший експорт.

Після оновлення `chats_data.json` змініть версію кешу в `sw.js` (наприклад, `snapeverse-v2-5`), інакше встановлений PWA може показувати старі дані.

## Керування сайтом

- **Дата сцени** — випадаючий список із підписом, хто був у той день: Северус, Люціус або обидва. Вибір дати відразу відкриває першу сцену.
- **Сортування** — спочатку старі/нові, найдовші/найкоротші.
- **Персонаж** — `Усі`, `Северус`, `Люціус`, `Обидва`.
- **Теми** — окреме вікно з чотирма категоріями.
- **Пошук** — у реальному часі по всіх повідомленнях. Режим **«Фраза»** (за замовчуванням) шукає точну фразу, режим **«Слова»** — окремі слова. Збіги підсвічуються, є перехід до першого збігу.
- **Цитати** — клік на блок відповіді плавно прокручує до оригінального повідомлення. Після переходу з'являється кнопка зі стрілкою вниз, щоб повернутися туди, де ви читали.
- **Медіа** — наявні фото, GIF, відео та стікери показуються в повідомленнях; клік відкриває збільшений перегляд.
- **Реакції** — наведіть курсор, натисніть правою кнопкою або затисніть на телефоні, щоб побачити, хто поставив реакцію. Telegram-експорт зберігає лише 1–3 імені на реакцію; у вікні написано, скільки імен збережено з усієї кількості.
- **Аватари** — кольорові кружки з ініціалами біля кожного повідомлення; якщо є файли в `avatars/`, показуються справжні фото Северуса й Люціуса.
- **Мова меню** — `UA` / `RU`. Діалоги завжди залишаються мовою оригіналу.
- **PWA** — після відкриття через https сайт можна додати на головний екран; інтерфейс і дані кешуються для офлайну.
- **Посилання на сцену** — `#scene=ID`; кнопка скопіювати посилання є в шапці чату.

## Приватність

Архів містить текст чатів, імена учасників, фото, GIF, відео та стікери. Публічне посилання бачить кожен, хто його отримав. Приватний GitHub Pages на безкоштовному тарифі недоступний. Для повністю приватного варіанта використовуйте `Snapeverse_Offline.html` або `Snapeverse_Offline_Media.html` і передавайте файл особисто.

У папці є `robots.txt` із забороною індексації, але це не замінює контроль доступу.
